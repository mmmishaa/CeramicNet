# YOLO26s

[v1](v1/README.md) и [v2](v2/README.md) — два опыта одной YOLO26s, а не разные архитектуры.

| Опыт | Train / val | Негативы train / val | Ultralytics |
| --- | --- | --- | --- |
| [v1](v1/README.md) | 243 / 61 | 40 / 10 | 8.4.183 |
| [v2](v2/README.md) | 248 / 145 | 45 / 94 | 8.4.184 |

Метрики и история выгружены из ClearML автора, примеры — из вывода ноутбуков в репозитории. Обучающие ноутбуки остаются в `notebooks/detection/yolo/`, отчёты ссылаются на них.

Для точного повторения у автора нужны исходный `data.yaml`, списки train/val с разметкой и версия Kaggle-датасета; полезны также `args.yaml`, `results.csv` и веса каждого запуска. Один и тот же seed без состава данных не фиксирует разбиение.
