# Воспроизведение YOLO v1

1. Открыть [исходный ноутбук](../../../../notebooks/detection/yolo/yolo_v1_train_pipeline.ipynb) в Kaggle с GPU или другом CUDA-окружении.
2. Использовать Ultralytics **8.4.183**, Python **3.13.15**, torch **2.11.0+cu128**, как в журнале; остальные параметры — в [training_config.json](training_config.json). В ноутбуке установка Ultralytics не закреплена, поэтому для повторения выбрать указанную версию явно.
3. Подключить исходный Kaggle-датасет и проверить `data_path`. Источник общего корпуса теперь зафиксирован: [Drive](https://drive.google.com/drive/folders/1MiKPCtREOFUfp6PxKqZUrviIB-TUI1Un), [снимок ZIP и SHA256](../../dataset_source.json). В архиве нет списков train/val и YOLO-меток: для точного повторения исторического запуска ещё нужны исходный `data.yaml` и использованные списки файлов с разметкой. Совпадения числа фотографий недостаточно.
4. Настроить личные SDK credentials через `clearml-init`/Secrets; пустые присваивания `CLEARML_API_ACCESS_KEY` и `CLEARML_API_SECRET_KEY` из исходного ноутбука удалить или заменить чтением Secrets. Ключи не коммитить. Без ClearML убрать только его инициализацию и закрытие, оставив параметры обучения.
5. В конце сохранить `best.pt`, `last.pt`, ONNX, `results.csv`, `args.yaml`, `data.yaml` и графики из папки запуска. Веса хранить вне Git; [исходная задача](https://app.clear.ml/projects/d6209850b8fb417bb10decb4dfaccfd8/tasks/fa3c17a1e8e544fea4628c326a4b5a3e/output/scalars), ID выходной модели `898fb3065d894a9f902a35c2aac5bc0e`.

В отчёте сохранены точные доступные скаляры ClearML. Шаги 0–49 соответствуют эпохам 1–50; шаг метрик 50 — отдельная проверка выбранного `best.pt`, в график как новая эпоха не включён. Картинки примеров извлечены из вывода исходного ноутбука, новые предсказания не запускались.

Новые примеры получены из ONNX команды на всех 23 запрошенных фото; confidence 0.75 взят из конфигурации приложения, а не подобран на этих кадрах. По журналу `optimizer="auto"` выбрал AdamW и начальный learning rate 0.002. Это не подбор разбиения train/val.
