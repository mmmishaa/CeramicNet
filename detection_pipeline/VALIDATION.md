## Данные

Проверены все 254 изображения и 257 bbox из COCO export. Реальные размеры совпали
с разметкой; ошибочных/выходящих за изображение bbox не обнаружено. Четыре пути
исправлены только в новых JSON. Train: 203 фото, 205 bbox, 201 предмет;
val: 51 фото, 52 bbox, 51 предмет. Пересечений по выведенным из имён предметам и
SHA256 нет. Seed 42, группировка примерно 80/20. Все фото положительные.

## Что выполнено

- 14 автоматических тестов без пропусков. Проверены split/дубликаты, старый API
  root_dir, новые ann_file/image_root, метки COCO 0 и разреженные ID, пустые targets,
  совместные преобразования bbox, letterbox и возврат координат, отдельные train/val,
  выбор профиля каждой модели и цветовой порядок RGB/BGR для MMDetection.
- Прочитаны все 254 реальных фото через StampDataset в общем пайплайне.
- Faster R-CNN: forward/backward со случайными весами на двух реальных фото
  (максимальная сторона 128 в быстрой проверке). Отдельно выполнен полный цикл
  из train_fasterrcnn.train на одной эпохе с двумя train и двумя val фото,
  без загрузки pretrained weights. Созданы checkpoint, predictions, config,
  history и metrics. Это проверка работоспособности, а не оценка качества.
- RT-DETRv2-S: официальная библиотека загрузила train/val батчи 8×3×640×640
  через TeamCocoDetection/StampDataset. Проверены метки и нормализованные bbox.
  Выполнены настоящий forward на одном val фото 640×640 со случайными весами,
  штатный postprocessor и перевод результата в общий COCO.
- MMDetection: восемь сгенерированных конфигов tiny/s × none/light/rotation/native
  разобраны через MMEngine. TeamAugment зарегистрирован в mmdet.registry и вызван
  через настоящий mmcv.BaseTransform; проверено перемещение bbox. Регистрация
  проверена без автоматического импорта остальных datasets/operators MMDetection.
- Общий COCO оценщик даёт mAP=1 на идеальных синтетических детекциях и mAP=0
  на пустых. Это проверка оценщика, не обученных моделей.

Окружение проверки: Python 3.12, torch 2.14.1, torchvision 0.29.1, CPU,
MMEngine, mmdet 3.3.0, mmcv-lite 2.1.0. Окружение и временные файлы находятся
вне отслеживаемого кода. Для настоящего RTMDet нужна полноценная сборка MMCV
с операторами и совместимая CUDA/PyTorch; локально его полный detector не запускался.

Полное обучение всех моделей и качество на независимом test не измерялись.
Экспорт обученных native checkpoints добавлен; проверка реальных обученных
весов возможна после их получения. Проверенные негативы и независимый test
ещё нужно собрать. Численные вероятности правильности bbox не калибровались.

## Общее логирование ClearML

Добавлен независимый от Dataset модуль experiment_tracking: local JSONL,
ClearML offline и серверный режим. В тестах используется настоящий ClearML SDK
2.1.12 в offline-режиме; запросы к рабочему серверу и реальные онлайн-эксперименты
не создавались. Проверены отдельные проекты detection/matching, разные split,
хеши файлов, статусы ошибок, пропуск других rank, инкрементальное чтение native
логов и сохранение RNG при инициализации SDK.

На двух реальных train и двух val фото выполнена одна эпоха Faster R-CNN со
случайными весами и стороной 128 в local и ClearML offline. Оба опыта записали
19 scalar значений и завершились; train loss совпал точно между режимами.
Это проверка логирования, не оценка обученных моделей. Для native моделей
проверены разрешение конфигураций и split-путей с overrides, сериализация и
чтение характерных JSONL записей; полное обучение с сервером не выполнялось.

Совместно выполнены 27 тестов детекции, интеграции Dataset и общего трекинга;
все прошли без пропусков. Проверены синтаксис Python и обновлённого ноутбука.
