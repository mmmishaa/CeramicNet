# CeramicNet

CeramicNet — проект для поиска клейм на старинных керамических изделиях и их сопоставления с каталогом эталонов.

## Как это работает

![Пайплайн CeramicNet](docs/assets/pipeline.png)

1. **Фото изделия**: на вход подается обычная фотография тарелки, чашки или вазы (обычно снимок донца с клеймом).
2. **Детекция (YOLO26s)**: нейросеть находит область клейма и вырезает ее.
3. **Предобработка (CLAHE)**: алгоритм убирает засветы, проявляет затертые линии рельефа и приводит картинку к квадрату $224 \times 224$ px.
4. **Векторизация (DINOv2)**: энкодер превращает изображение клейма в вектор из 384 чисел, описывающий его геометрическую форму.
5. **Поиск по базе**: вектор сравнивается со всеми эталонами из каталогов по косинусному сходству за пару миллисекунд.
6. **Результат**: список наиболее похожих клейм из справочников с указанием завода, книги, страницы и процента совпадения.

## Модели

* **Детектор (YOLO26s)** — локализует клеймо на керамике. При обучении в датасет специально добавили снимки керамики без клейм (с росписью, ручками и трещинами), чтобы модель не реагировала на посторонние детали.
* **Энкодер (DINOv2 ViT-S/14)** — извлекает признаки клейма. Дообучен на парах «эталон — поврежденный фрагмент» с контрастивной функцией потерь SupConLoss и майнером MultiSimilarityMiner, который учит модель отличать визуально похожие клейма разных заводов.
* **Индекс эталонов** — готовая база клейм из справочников, сохраненная в виде матрицы векторов в файле `data/books_index/stamp_books_index_v2.npz`. Новые клейма можно добавлять в базу без переобучения моделей.

## Установка

Требуется Python версии 3.9 или выше.

```bash
git clone https://github.com/mmmishaa/CeramicNet
cd CeramicNet

python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# .venv\Scripts\activate   # Для Windows

pip install -r requirements.txt
```

## Скачивание весов и данных

Веса моделей, каталоги справочников и индексы скачиваются из Google Drive с помощью скрипта `scripts/download_artifacts.py`.

### Полная загрузка

> Для получения доступа к архиву и ID папки на Google Drive обратитесь к авторам репозитория.

```bash
python -m scripts.download_artifacts --folder_id <ID_ПАПКИ_GOOGLE_DRIVE>
```

Скрипт загрузит и разложит файлы по нужным папкам:
* `weights/detection_weights/` — веса детектора (`yolo26s_v2.onnx`).
* `weights/retrieval_weights/` — веса энкодера (`stamp_encoder_v2.onnx`).
* `data/books/` — сканы страниц и вырезанные клейма из справочников.
* `data/books_index/` — векторный индекс для поиска (`stamp_books_index_v2.npz`).
* `data/ceramic_dataset/` — тестовые и обучающие фотографии.

### Выборочная загрузка

Если не нужно скачивать тяжелые датасеты фотографий, можно загрузить только модели и индекс через флаг `--only`:

```bash
# Скачать только веса моделей и векторный индекс
python -m scripts.download_artifacts --folder_id <ID_ПАПКИ> --only detection retrieval index

# Скачать только книги-справочники
python -m scripts.download_artifacts --folder_id <ID_ПАПКИ> --only books
```

Доступные категории: `detection`, `retrieval`, `index`, `books`, `dataset`.

Посмотреть список файлов в папке без скачивания:

```bash
python -m scripts.download_artifacts --folder_id <ID_ПАПКИ> --list
```

## Запуск (main.py)

Вся работа с системой выполняется через скрипт `main.py`.

### Тест на случайном фото из датасета

Запуск пайплайна на случайном снимке с показом окна с результатом:

```bash
python main.py --random 1 --show
```

### Проверка своего изображения

```bash
python main.py --input path/to/plate.jpg --show
```

### Пакетная обработка папки с фото

```bash
python main.py --input path/to/folder/ --top-k 5
```

### Поиск по уже вырезанному клейму (без детектора)

Если у вас уже есть кроп клейма, детектор можно отключить флагом `--no-detect`:

```bash
python main.py --input path/to/stamp.png --no-detect --show
```

### Выбор модели энкодера и числа кандидатов

```bash
python main.py --input path/to/plate.jpg --model stamp_encoder_v2 --top-k 5 --show
```

### Основные аргументы main.py:
* `--input <путь>` — путь к файлу изображения или к папке с изображениями.
* `--random [N]` — взять N случайных снимков из датасета (по умолчанию 1).
* `--model <имя>` — версия энкодера из конфига (`stamp_encoder_v2`).
* `--top-k <число>` — сколько похожих клейм выводить в ответе (например, 5).
* `--no-detect` — отключить детектор и передать изображение напрямую в энкодер.
* `--show` — открыть окно с визуализацией: исходное фото, рамка детекции и найденные эталоны.
* `--detection-config <путь>` — путь к конфигу детектора (по умолчанию `configs/detection/detection_config.yaml`).
* `--retrieval-config <путь>` — путь к конфигу ретривала (по умолчанию `configs/retrieval/retrieval_config.yaml`).

## Структура проекта

```text
CeramicNet/
├── configs/                   # Конфигурационные файлы
│   ├── detection/             # Пороги и параметры детектора
│   └── retrieval/             # Параметры энкодеров и каталогов
├── data/                      # Данные (скачиваются скриптом)
│   ├── books/                 # Сканы справочников клейм
│   ├── books_index/           # Векторный индекс эталонов (.npz)
│   └── ceramic_dataset/       # Фотографии керамики
├── notebooks/                 # Ноутбуки обучения (Kaggle / ClearML)
│   ├── detection/yolo/        # Обучение YOLO26s
│   └── retrieval/             # Обучение энкодера DINOv2
├── scripts/                   # Вспомогательные скрипты
│   └── download_artifacts.py  # Скачивание весов и данных с Google Drive
├── src/                       # Исходный код системы
│   ├── detection/             # Модуль детекции на ONNX Runtime
│   ├── retrieval/             # Энкодер DINOv2, индекс, книги
│   └── pipeline.py            # Логика сквозного пайплайна
├── weights/                   # Веса моделей ONNX
└── main.py                    # Главная точка входа
```
